## Source-review decisions

- No raw provider page, PDF, screenshot, source dataset or provider example code is vendored. The exact OFL-1.1 Noto font and its license are intentionally vendored as a reviewed deterministic build asset.
- The pack stores short repository-authored paraphrases plus URL/publisher/title/retrieval/scope/version/terms metadata.
- CLDR values are version-pinned to 49; a later version must produce a new pack version and context digest.
- Japanese Digital Agency content is explicitly attributed and identified as transformed.
- The German official rule document is citation-only; the fixture does not reproduce the rules or claim legal correctness.
- SDD-012 adds pinned `sharp@0.35.3` (Apache-2.0; prebuilt libvips runtime notice retained) and `opentype.js@1.3.4` (MIT), plus a repository-owned deterministic ZIP store writer. It introduces no AGPL/Postiz component, vector database, crawler, account integration or external action.
- SDD-012 copies no provider SDK, provider example code, competitor/Postiz/AGPL source or sample output. The asset manifest and dependency review record exact versions, digests, licenses, NOTICE/SBOM decisions and fail-closed boundaries; they make no API availability, media quality, pricing, rights, platform-compliance or production-readiness guarantee.
