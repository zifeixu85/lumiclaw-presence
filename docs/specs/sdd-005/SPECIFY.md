# SDD-005 Specify

## User story

As a team operating in several countries, I want LumiClaw to combine our own approved market knowledge with a small, sourced public baseline so that each Agent uses the correct market context and I can see where the guidance came from.

## Observable result

- US, JP and DE can be selected in a public-safe evidence surface.
- Each selection shows a distinct market brief, pack/version/sources and human questions.
- An Organization override is visibly separate from the public pack.
- One incompatible override produces a conflict rather than a silent result.
- Agent role evidence shows minimum Producer context and richer Auditor provenance.

## Non-result

The slice does not generate a legally or culturally certified post, connect an account, publish content, ingest a customer document or prove commercial outcomes.
